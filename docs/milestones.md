# Milestones

## Milestone 0: Primera versión del problema en código

**Objetivo:** pasar a código los conceptos básicos del problema que salen en las historias de usuario, siguiendo el diseño dirigido por el dominio, para luego poder implementar la lógica de negocio. Es un producto interno: en esta etapa todavía no hay funcionalidad.

**Entrega:**
El código, en el lenguaje elegido, con esos conceptos, junto a un documento explicando las decisiones: qué concepto del problema representa cada elemento y por qué.

**Comprobación** el código pasa la comprobación de sintaxis, cada elemento se puede justificar a partir de las historias de usuario, y los cambios se han revisado y aprobado en un pull request.

## Milestone 1: Primer caso completo resuelto

**Objetivo:** verificar que lo entregado en el milestone 0 sirve para resolver de principio a fin un caso sencillo del problema. Sigue siendo interno, todavía sin interfaz para el usuario.

**Entrega**
La lógica de negocio mínima para resolver ese caso y las pruebas automáticas de esa lógica.

**Comprobación**  las pruebas se ejecutan automáticamente y pasan, y los cambios se han revisado y aprobado en un pull request.
